## 最小配置

在 `src/main/resources/application.properties` 中添加：

```properties
spring.application.name=agent-demo
liteflow.rule-source=agent/flow.el.xml
liteflow.agent.openai-compatible.deepseek.api-key=${DEEPSEEK_API_KEY}
```

启动前设置环境变量 `DEEPSEEK_API_KEY`，值为你的模型 API Key。

`spring.application.name` 用于区分不同应用的会话数据，部署后应保持稳定。

## YAML 写法

与上面的 properties 二选一即可：

```yaml
spring:
  application:
    name: agent-demo
liteflow:
  rule-source: agent/flow.el.xml
  agent:
    openai-compatible:
      deepseek:
        api-key: ${DEEPSEEK_API_KEY}
```

## 这份配置会启用什么

会话和聊天历史默认保存到进程工作目录下的 `data/agent-state`。默认使用本地文件后端，后续的组件示例会显式关闭 Shell，因此不必配置命令目录。

`liteflow.agent.application-name` 默认取 `spring.application.name`。如果应用已有名称，直接沿用；需要单独指定 Agent 数据的应用标识时，再设置该属性。应用标识必须有值，不能包含 `/`、`\`、`..` 等路径字符。

需要执行脚本时，按 [Shell 工具](/pages/agent-shell-tools/) 配置本地目录，或使用 [Docker 沙箱](/pages/agent-docker/)。多实例部署可选择 [Redis 或 MySQL 存储](/pages/agent-memory/)。
