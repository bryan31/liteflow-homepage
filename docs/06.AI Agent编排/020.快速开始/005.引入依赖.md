本系列使用 **LiteFlow 2.16.2、JDK 17+** 和已有的 Spring Boot 项目。先创建一个能流式回复的对话 Agent，不需要 Docker 或数据库。

## 添加 Maven 依赖

在已有 Spring Boot 项目的 `pom.xml` 中添加：

```xml
<properties>
    <liteflow.version>2.16.2</liteflow.version>
</properties>

<dependencies>
    <dependency>
        <groupId>com.yomahub</groupId>
        <artifactId>liteflow-spring-boot-starter</artifactId>
        <version>${liteflow.version}</version>
    </dependency>
    <dependency>
        <groupId>com.yomahub</groupId>
        <artifactId>liteflow-agent-core</artifactId>
        <version>${liteflow.version}</version>
    </dependency>
    <dependency>
        <groupId>com.yomahub</groupId>
        <artifactId>liteflow-agent-openai</artifactId>
        <version>${liteflow.version}</version>
    </dependency>
</dependencies>
```

Spring Boot 4 使用 `liteflow-spring-boot4-starter`。各 LiteFlow 模块版本保持一致，AgentScope 依赖会自动引入。如果所用 Maven 仓库还未提供该版本，可先从源码安装，步骤见[演示项目](/pages/agent-example/)。

模型平台可以替换为 `liteflow-agent-anthropic`、`liteflow-agent-gemini` 或 `liteflow-agent-dashscope`，具体对应关系见[模型配置](/pages/agent-models/)。
