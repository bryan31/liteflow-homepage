## 运行客服分流演示

示例仓库 [liteflow-agent-example](https://github.com/bryan31/liteflow-agent-example) 提供了可直接操作的 [liteflow-agent-jev-switch 模块](https://github.com/bryan31/liteflow-agent-example/tree/main/liteflow-agent-jev-switch)，可以用来测试真实客服消息的分流效果。

页面支持自由输入、按类别选择 14 条预设问题，并展示实际分支、置信度、各选项概率、执行路径、组件回复和处理时间。演示包含退款、换货、物流、发票、投诉、咨询 6 个业务组件与人工兜底组件。

![Jev 客服分流演示：商品换货、置信度、候选概率与处理时间](/img/agent-example/jev-customer-routing.png)

截图中，换货选项概率为 **87%**，模型置信度为 **85%**；服务端处理时间为 **328 ms**，浏览器端到端耗时为 **339 ms**。处理时间包含 Jev 网络调用和 LiteFlow 流程执行，不是模型纯推理时间。这是一条请求的展示结果，不代表固定延迟或准确率保证。

## 启动演示

在示例仓库根目录执行：

```bash
export JEV_API_KEY='填写你的 TypeSafe API Key'
mvn -pl liteflow-agent-jev-switch -am clean package -DskipTests
mvn -pl liteflow-agent-jev-switch spring-boot:run
```

如需通过 OpenRouter 调用，完成打包后改用以下启动方式：

```bash
export JEV_API_KEY='填写你的 OpenRouter API Key'
mvn -pl liteflow-agent-jev-switch spring-boot:run -Dspring-boot.run.arguments=--liteflow.agent.jev.provider=openrouter
```

演示使用 `JEV_API_KEY` 注入所选 provider 的凭据。`typesafe` 为默认入口；选择 `openrouter` 后，默认地址与模型随之切换。本地配置若已显式设置 `base-url` 或 `model`，需移除旧值或同步更新，详见[依赖与配置](/pages/agent-jev-config/)。

启动后访问 [http://localhost:8906/](http://localhost:8906/)。使用两种 provider 的默认入口时，均无需额外设置基础地址，也不需要 DeepSeek 凭据、数据库或 Docker。尚未安装 LiteFlow 依赖时，先按[演示项目的源码安装说明](/pages/agent-example/#依赖尚未在-maven-仓库中可用时)完成安装。

## 后端选项与前端预设

示例中的选项与判断说明直接写在 `SupportRouter.choices()` 中。页面预设问题、名称和缩写在前端 `scenarios.mjs` 中维护；后端 `/api/support/options` 只返回选项与模型、阈值、超时配置，不返回预设问题或 API Key。

## 运行离线测试

可运行的演示模块与框架自动化测试分开存放：框架的 HTTP 协议、分支执行、异常、超时及前端结果处理测试统一位于 LiteFlow 源码仓库的 `liteflow-testcase-el/liteflow-testcase-el-agent-jev`。这些离线测试不调用真实模型：

```bash
# 在 LiteFlow 源码仓库根目录执行
mvn -pl liteflow-testcase-el/liteflow-testcase-el-agent-jev -am test -DskipTests=false
node --test liteflow-testcase-el/liteflow-testcase-el-agent-jev/src/test/js/decision-view.test.mjs
```

前端测试默认从同级 `liteflow-agent-example` 仓库读取页面模块；目录不同，可通过 `JEV_DEMO_STATIC` 指定演示模块的 `src/main/resources/static` 绝对路径。更多运行说明见[演示模块 README](https://github.com/bryan31/liteflow-agent-example/tree/main/liteflow-agent-jev-switch)。
