## 让主 Agent 自行分派子任务

EL 适合业务已经确定的流程；希望由主 Agent 决定是否分派子任务时，可以声明子代理。该能力需要 `DOCKER` 或自定义后端，本地 `GUARDED_LOCAL` 不启用子代理。

在已配置 Docker 的组件中添加：

```java
import io.agentscope.harness.agent.subagent.SubagentDeclaration;
import io.agentscope.harness.agent.subagent.WorkspaceMode;
import java.util.List;

@Override
protected List<SubagentDeclaration> subagents() {
    return List.of(SubagentDeclaration.builder()
            .name("reviewer")
            .description("检查主代理提供的结论，指出遗漏和矛盾")
            .inlineAgentsBody("根据提供的事实审查，不编造依据。")
            .workspaceMode(WorkspaceMode.ISOLATED)
            .build());
}
```

默认继承父模型，迭代上限为 10。`ISOLATED` 使用独立工作区，`SHARED` 与主代理共享工作区。模型根据描述决定何时调用，并非每次请求都会启动子代理。

需要模型先形成计划时，可另外覆写 `enablePlanMode()` 返回 `true`。如果还需要用户批准计划，按[人工确认](/pages/agent-hitl/)为 `plan_exit` 设置 `ASK` 规则并接入确认处理器。
